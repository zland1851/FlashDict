# Chrome Web Store 商店資訊 - FlashDict (繁體中文)

## 基本資訊

**擴充功能名稱:** FlashDict

**簡短描述 (132字元以內):**
```
即時查詢單字釋義，一鍵建立 Anki 閃卡。支援多種線上詞典，助力高效學習外語。
```
(42字元)

**詳細描述:**
```
FlashDict 是一款專為語言學習者打造的 Chrome 擴充功能，讓你在瀏覽網頁時即時查詞並建立 Anki 閃卡。

主要功能：

• 即時查詞 - 選取網頁上的任意單字即可彈出釋義。支援雙擊選字或拖曳選取。

• 多詞典支援 - 內建 Collins、Oxford 等詞典，還可連接劍橋、有道、Urban Dictionary 等線上詞典。

• Anki 整合 - 一鍵建立閃卡，支援 AnkiConnect（桌面版）和 AnkiWeb（雲端）。自動擷取單字、釋義、音標、例句和來源網址。

• 發音朗讀 - 支援英式和美式發音。

• 雙語支援 - 支援單語和雙語詞典。適合學習英語、法語、西班牙語、德語、俄語等語言的使用者。

• 自訂配置 - 可配置快捷鍵、選擇偏好詞典、自訂 Anki 筆記欄位等。

• 快捷鍵操作 - 使用 Alt+Q 開關擴充功能。按住 Shift 選取連結中的文字進行查詞。

支援的詞典：
- Collins 英漢/英英詞典
- 劍橋英漢/英法/法英詞典
- 牛津英漢詞典
- 有道英漢/法漢詞典
- Urban Dictionary
- Spanishdict 西英詞典
- 更多詞典...

ANKI 整合：
支援 Anki 桌面版（透過 AnkiConnect 外掛）或 AnkiWeb 雲端服務。自動對應欄位：
- Expression（單字）
- Reading（音標）
- Definition（釋義）
- Sentence（上下文例句）
- URL（來源網址）
- Audio（發音）

無論你是學生、語言學習者，還是希望在瀏覽網頁時累積詞彙的人，FlashDict 都是你的理想選擇。

本擴充功能開源：https://github.com/zland1851/FlashDict
```
