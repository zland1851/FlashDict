# Chrome Web Store 商店信息 - FlashDict (简体中文)

## 基本信息

**扩展名称:** FlashDict

**简短描述 (132字符以内):**
```
即时查询单词释义，一键创建 Anki 闪卡。支持多种在线词典，助力高效学习外语。
```
(42字符)

**详细描述:**
```
FlashDict 是一款专为语言学习者打造的 Chrome 扩展，让你在浏览网页时即时查词并创建 Anki 闪卡。

主要功能：

• 即时查词 - 选中网页上的任意单词即可弹出释义。支持双击选词或拖动选择。

• 多词典支持 - 内置 Collins、Oxford 等词典，还可连接剑桥、有道、Urban Dictionary 等在线词典。

• Anki 集成 - 一键创建闪卡，支持 AnkiConnect（桌面版）和 AnkiWeb（云端）。自动抓取单词、释义、音标、例句和来源网址。

• 发音朗读 - 支持英式和美式发音。

• 双语支持 - 支持单语和双语词典。适合学习英语、法语、西班牙语、德语、俄语等语言的用户。

• 自定义配置 - 可配置快捷键、选择偏好词典、自定义 Anki 笔记字段等。

• 快捷键操作 - 使用 Alt+Q 开关扩展。按住 Shift 选中链接中的文字进行查词。

支持的词典：
- Collins 英汉/英英词典
- 剑桥英汉/英法/法英词典
- 牛津英汉词典
- 有道英汉/法汉词典
- Urban Dictionary
- Spanishdict 西英词典
- 更多词典...

ANKI 集成：
支持 Anki 桌面版（通过 AnkiConnect 插件）或 AnkiWeb 云服务。自动映射字段：
- Expression（单词）
- Reading（音标）
- Definition（释义）
- Sentence（上下文例句）
- URL（来源网址）
- Audio（发音）

无论你是学生、语言学习者，还是希望在浏览网页时积累词汇的人，FlashDict 都是你的理想选择。

本扩展开源：https://github.com/zland1851/FlashDict
```
