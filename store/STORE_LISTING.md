**Detailed Description:**
```
FlashDict is a powerful Chrome extension for language learners that lets you look up word definitions and create Anki flashcards directly from any webpage.

KEY FEATURES:

• Instant Word Lookup - Simply select any word on a webpage to see its definition in a popup. Double-click or drag to select text.

• Multiple Dictionary Support - Choose from built-in dictionaries (Collins, Oxford) or connect to online dictionaries including Cambridge, Youdao, Urban Dictionary, and more.

• Anki Integration - Create flashcards with one click using AnkiConnect (desktop) or AnkiWeb (cloud). Automatically captures the word, definition, pronunciation, example sentence, and source URL.

• Audio Pronunciation - Listen to word pronunciations with support for both UK and US accents.

• Bilingual Support - Works with monolingual and bilingual dictionaries. Perfect for English learners studying with Chinese, French, Spanish, German, or Russian translations.

• Customizable - Configure hotkeys, select your preferred dictionary, customize Anki note fields, and more.

• Keyboard Shortcuts - Use Alt+Q to toggle the extension. Hold Shift while selecting to look up words in links.

SUPPORTED DICTIONARIES:
- Collins English-Chinese / English-English
- Cambridge English-Chinese / English-French / French-English
- Oxford English-Chinese
- Youdao English-Chinese / French-Chinese
- Urban Dictionary
- Spanishdict
- And many more...

ANKI INTEGRATION:
Works with Anki desktop (via AnkiConnect addon) or AnkiWeb cloud service. Automatically maps fields:
- Expression (the word)
- Reading (pronunciation/phonetics)
- Definition
- Sentence (context from the webpage)
- URL (source page)
- Audio

Perfect for students, language learners, and anyone who wants to build vocabulary while browsing the web.

This extension is open source: https://github.com/zland1851/FlashDict
```
